# Demo Scenario

`npm run seed` creates `NEXTMOVE株式会社` as donor and `AI Seed株式会社` as
startup, with desks, chairs, monitors, startup needs, reciprocal service
offers/wants, and the supplied office photos in private Storage.

Open the matches page and run “マッチを再計算”. Accept first as the startup and
then as the donor. A database trigger creates the transfer automatically.
